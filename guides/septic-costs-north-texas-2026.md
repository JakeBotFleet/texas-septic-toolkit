# How can I compare septic quotes without invented price ranges?

> Build a budget from current written quotes for the same evaluated site and scope. This repository has no verified market-price dataset.

Reviewed **2026-10-18**. The filename is retained for existing links; it is not evidence of a 2026 price survey.

TCEQ's [owner advice](https://www.tceq.texas.gov/permitting/ossf/ossfadvice.html) recommends obtaining multiple estimates, checking references, and documenting decisions. It also identifies continuing operation and maintenance as part of system selection.

Use this comparison worksheet:

| Item | Evidence to request |
| --- | --- |
| Site evaluation and planning | Who performs it, qualifications, deliverables, and exclusions |
| Authority fees | Current authority fee schedule and applicable category |
| Equipment and installation | Proposed approved configuration, quantities, materials, access, and scope |
| Excavation and restoration | Assumptions about rock, clearing, spoil, grading, and cleanup |
| Changes | Written method for approving added work and prices |
| Ongoing work | Maintenance obligations, service scope, consumables, and power requirements |
| Completion | Required inspections, corrections, documents, and payment milestones |

For Palo Pinto County fees, use the [official Public Works page](https://www.co.palo-pinto.tx.us/page/PublicWorksDepartment). For other parcels, confirm the applicable authority first.

A cost tool should total **user-supplied, documented amounts** and show exclusions. Do not label a generated total as an Out West Septic quote, regional average, or evidence of completed jobs. [Out West Septic](https://outwestseptic.com) is the affiliated project for this automated research; request a current written scope from any contractor you consider.
