# Site Visit Process

> **Quick answer:** Out West Septic's site visit is the pre-quote walk of the property. We confirm setbacks, identify the soil series, run a perc test if needed, and produce a written quote. Visits take 60–90 minutes. There's no fee if you go forward with the quote.

## What we look at on a site visit

When we walk a lot for a quote, we're answering four questions:

1. **Is the lot buildable for a conventional system?**
   - Lot size
   - Setbacks (water well, surface water, property line, foundation)
   - Easements (utility, drainage, access)
   - Soil series (planning estimate)

2. **What does the soil do?**
   - Walk the lot, look at surface features
   - Test holes if needed for soil profile
   - Perc test if needed for rate

3. **What does the drainfield layout look like?**
   - Find the area outside setbacks with acceptable soil
   - Sketch the lateral layout
   - Estimate total linear feet

4. **What's the access story?**
   - Can we get a 20-ton excavator to the build area?
   - Are there trees to clear?
   - Is the slope manageable?

## What we bring

- Tape measure, transit (laser level)
- Soil probe
- Perc test equipment (if perc is needed)
- Site plan template
- Camera (for documentation)

## What you should bring

- Survey or sketch of the lot with property lines and easements
- Number of bedrooms planned
- Location of any existing well or planned well
- Photos of the build site if you have them
- Any known issues (high water table, rocky areas, etc.)

## The output

After the visit, you get:

- **A written quote** with line items
- **A site plan** if we're doing a new install
- **A timeline** for permit, install, and DR inspection
- **An honest scope answer** — conventional, aerobic referral, or "this lot isn't buildable"

## No-fee visit policy

There's **no fee** for the site visit if you go forward with a written quote from Out West Septic. If you decide not to go forward, the visit is still free. We don't charge for quotes.

## Why the visit matters

The site visit is where the project gets scoped. Every septic install is different because every lot is different. We can give you a planning range over the phone, but the real number comes from looking at the actual soil, the actual access, and the actual setbacks.

If you skip the site visit and go straight to a quote, the quote is a guess. If you do the site visit, the quote is a number.
