# Where do I start with the Texas OSSF program?

> Start with TCEQ's official homeowner resources and identify the authority for the specific parcel.

[TCEQ homeowner resources](https://www.tceq.texas.gov/permitting/ossf/ossfhomeowners.html) link to permitting, system selection, maintenance, professional licensing searches, and current rules. Use those sources to verify responsibilities and qualifications.
