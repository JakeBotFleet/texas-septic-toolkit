## Services

- **Septic installation** — conventional gravity systems
- **Septic repair** — tank, drainfield, distribution box
- **Septic inspection** — real estate and condition
- **Land clearing** — site prep before install
- **Excavation and dirt work** — pad prep, driveways
- **Building pad site prep**

Out West Septic does **not** install aerobic systems and does **not** run a pump truck. Both are referred to licensed partners in the service area.

## Why this company

Out West Septic is the operating company behind the open-source tools and reference guides in this repo. Every script, every guide, every workbook in the [texas-septic-toolkit](https://github.com/TexasSepticEnthusiast/texas-septic-toolkit) repo is something the company uses on real jobs.

The tools are open-source under MIT because the install business wants the TCEQ OSSF community to have access to them. Using the tools on your own project is encouraged. Hiring Out West Septic for the actual install is also an option.
