# Where should I check OSSF separation distances?

> Use the applicable component, feature, table entry, footnotes, and local requirements. This repository does not provide a universal setback table.

The [2023 TCEQ adoption document](https://www.tceq.texas.gov/downloads/rules/adoptions/21030285_ado.pdf/@@download/file/21030285_ado.pdf), Figure 30 TAC §285.91(10), Table X, shows separate columns for tanks, soil absorption systems, lined evapotranspiration beds, sewer pipes, surface application, and drip irrigation. Its feature definitions and footnotes matter.

This is dated source evidence. Check the [current rules through TCEQ](https://www.tceq.texas.gov/rules/indxpdf.html) and the local authority before using a distance. The live current-rule text was not independently retrieved in this review.

For each dimension on a proposed plan, record:

| Record | Detail |
| --- | --- |
| Component and feature | Exact system part and neighboring feature |
| Requirement | Applicable rule, table, row/column, footnote, and local order |
| Measured distance | Survey/plan basis and units |
| Review | Responsible professional and authority confirmation |

Meeting one distance does not establish a complete suitable layout. See [tool limits](../guides/tool-inputs-and-sources.md) and [Possum Kingdom jurisdiction](../guides/possum-kingdom-lake-septic-considerations.md).
