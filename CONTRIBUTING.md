# Contributing

Thanks for considering a contribution to the Texas Septic Toolkit. This repo exists to support TCEQ OSSF-licensed septic installers and curious homeowners across rural North Texas. The maintainer is James "Tanner" Coupland of [Out West Septic](https://outwestseptic.com) (TCEQ OSSF Installer I, license OS0041298).

## What belongs here

- Python tools that encode TCEQ Chapter 285 rules, regional soil profiles, and field workflows
- Excel templates that automate the repetitive parts of inspection, site eval, and quoting
- Reference guides that answer real questions from rural North Texas homeowners and installers

## What does not belong here

- Anything that implies Out West Septic installs aerobic systems (we install conventional only)
- Anything that implies we run a pump truck (we do not)
- Anything that implies we serve Parker or Tarrant County (per binding SEO strategy)
- Invented costs, timelines, or equipment limits that Tanner has not confirmed
- Doorway-style city/county pages with no real local substance

## Style

- Python: PEP 8, type hints on public functions, docstrings that include the SERVICE_AREAS block from the [branding rules in note 48995](https://hjarni.com/notes/48995)
- Excel: keep the branded header (Out West Septic / TCEQ OSSF Installer I / OS0041298 / Lone Camp, TX) and footer (outwestseptic.com / Serving Palo Pinto County & Rural North Texas / 940.452.0598)
- Markdown: H1 as a question, quick-answer blockquote at the top, plain language, branded footer with the seven priority counties

## Pull requests

1. Fork the repo.
2. Create a feature branch (`git checkout -b feature/my-improvement`).
3. Make your change with clear commit messages.
4. Run any affected scripts end-to-end and paste a sample of the output in the PR description.
5. Open a PR. Tanner reviews PRs weekly.

## Issues

Use the GitHub Issues tab for bugs, feature requests, and discussion threads. Tanner personally triages the queue.
